<p align="center"><strong>2D desktop platformer · Python · pygame-ce · собственный редактор уровней · Windows</strong></p>

**Cat vs Ghosts** — законченный 2D-платформер, разработанный как долгосрочный личный проект на Python. Небольшой прототип постепенно превратился в полноценную Windows-игру с многоэтапной кампанией, профилями и сохранениями, локализацией, собственными инструментами создания контента, калибровкой производительности, GPU-оптимизацией и release pipeline.

> **Статус:** v1.0.0 — Windows-сборка завершена и протестирована как на старом ноутбуке с гибридной графикой, так и на современном ноутбуке с NVIDIA.

> **Исходный код:** production-репозиторий остаётся приватным. Этот публичный репозиторий предназначен для портфолио и намеренно не публикует полный код игры и редактора уровней.

## Ключевые возможности

- Многоэтапная платформенная кампания с разными визуальными темами и боссами
- Собственный редактор уровней, использованный для создания и переработки кампании
- Object-layer / registry кистей для повторно используемых игровых и декоративных объектов
- Профили игроков, прогресс кампании, сохранение/загрузка, настройки и скриншоты
- Навигация клавиатурой и мышью по модели **last-input-wins**
- Локализация на **английский, польский, русский и украинский**
- Автоматическая калибровка производительности под разные классы оборудования
- Оптимизация рендера, включая оптимизированные фоновые пайплайны
- Windows-сборка через **PyInstaller** и интеграция установщика
- Development-only профайлеры исключаются из финальной сборки

Редактор поддерживает несколько масштабов, навигацию по большим картам, повторно используемые кисти, декоративные и игровые сущности, якоря объектов, выбор фона/темы и прямой запуск теста редактируемого этапа. Object-layer построен вокруг registry, поэтому новый контент можно добавлять без отдельного hard-code для каждого объекта.

## Инженерные особенности

### Работа с производительностью на разном оборудовании
Игра включает автоматический benchmark/calibration этап, который измеряет рендеринг и логические нагрузки и сохраняет локальный профиль производительности. Оптимизация проверялась и на современном оборудовании, и на старом ноутбуке с гибридной Intel/NVIDIA-графикой. Windows-релиз также проверялся на ноутбуке с NVIDIA RTX 3060.

### Content pipeline
Объекты описываются через registry вместо индивидуального hard-code внутри данных уровней. Метаданные кистей могут включать asset references, anchors, gameplay roles и данные, связанные с производительностью.

### Разделение release/debug
PyInstaller-конфигурация явно исключает development-only модули профайлера, при этом упаковывая необходимые runtime assets и уровни.

### Локализация и данные игрока
Игра поддерживает EN / PL / RU / UA через систему ключевых переводов с английским fallback. Профили, сохранения, прогресс кампании и настройки находятся вне каталога упакованного приложения.
